## 三、功能与用途

### 14. 软件用途
```
本软件是面向小企业主的网站搭建与管理平台。用户无需编写代码，
通过填表方式即可创建、编辑和发布企业展示型网站。软件将用户填写的
内容生成为纯静态 HTML/CSS/JS 文件，可部署到任何 CDN 或 Web 服务器，
不依赖后端运行时环境。

目标用户：制造业、贸易、服务业、餐饮业等不会编程的小企业老板。
```

### 15. 技术特点
```
1. 静态站点生成：将用户内容编译为纯 HTML 文件输出，无需服务器端
   运行时，网站加载速度快、安全性高。

2. 多因子账户身份系统：支持邮箱和手机号双渠道注册与登录，统一
   AccountIdentity 身份标识管理，支持绑定多个邮箱/手机号、设置
   主身份和解除非主身份绑定。

3. 安全认证体系：采用"邮箱/手机号 + 密码"主登录方式，辅以 6 位
   一次性验证码通道（注册、找回密码、绑定新身份）；密码使用
   Werkzeug 自适应哈希算法存储，支持 30 天多设备持久会话和远程
   设备撤销；修改密码后自动撤销其他所有设备会话。

4. 一次性验证码系统：注册、登录、找回密码和身份绑定统一走验证码
   通道；验证码 10 分钟有效、最多 5 次尝试、按账号限流，生成新码
   自动作废旧码；支持 SMTP 邮箱发送和供应商无关的 JSON Webhook
   短信发送。

5. 账户中心工作区：独立 iframe 隔离的账户管理界面，在不刷新和
   不销毁编辑器状态的前提下进入；覆盖个人资料编辑、我的站点管理、
   账号安全设置（密码修改、身份绑定、设备管理）和回收站四大板块。

6. 模块化页面构建（Block 系统）：页面由可复用的功能块（导航栏、
   产品展示、联系方式等）组装而成，用户只需选择模块并填写内容。

7. 数据文件存储：网站内容存储为 YAML 文件而非数据库记录，便于
   导出、备份和迁移，平台关停后用户数据不丢失。

8. 站点软删除与回收站：删除站点仅设置 soft_deleted_at 标记，
   数据库记录和磁盘文件完整保留，支持从回收站一键恢复。

9. 一键导出 ZIP：用户可将完整网站打包下载，部署到任意 CDN。

10. 字体子集化：自动提取网站实际使用的字符，将中文字体从 5-10MB
    压缩至 15KB 以下，提升首屏加载速度。

11. AI 辅助翻译：集成大语言模型接口，自动翻译网站内容到多语言版本。

12. 模板系统：支持多套网站模板，用户可切换模板而不丢失内容数据。
```

### 16. 主要功能模块
```
1. 用户认证系统 —— 邮箱/手机号 + 密码注册登录，验证码找回密码
2. 账户中心 —— 个人资料、我的站点、账号安全、回收站四大工作区
3. 身份管理 —— 多邮箱/手机号绑定、主身份设置、身份验证与解绑
4. 会话管理 —— 30 天多设备持久登录、设备列表查看、远程撤销
5. 站点管理 —— 创建/删除/切换站点、基本信息设置（Logo、主色、菜单）
6. 页面编辑器 —— 可视化页面布局，添加/删除/排序功能模块
7. 数据集管理 —— 产品列表、文章列表等结构化数据的增删改查
8. 媒体库 —— 图片上传、管理、自动压缩
9. 模板选择 —— 多套网站模板预览与切换
10. 静态站点生成 —— Jinja2 模板引擎渲染，输出纯静态 HTML
11. 一键导出 —— 打包完整站点为 ZIP 文件下载
12. 字体子集化 —— 中文字体按需提取
13. AI 翻译 —— 网站内容多语言自动翻译
14. 站点回收站 —— 软删除与恢复，数据不丢失
```
