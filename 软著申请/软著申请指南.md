# 软件著作权申请指南

> 项目：小企业静态网站生成与管理平台
> 更新日期：2026-07-16

---

## 一、什么是软著

**计算机软件著作权**（简称"软著"）是中国版权保护中心对软件作品的官方登记认证。对于本项目而言，软著的价值在于：

| 用途 | 说明 |
|---|---|
| **上架应用商店** | 微信小程序、App Store、各大应用市场需要软著 |
| **高新技术企业认定** | 软著是高新技术企业申报的必备材料 |
| **双软认证** | 软件企业 + 软件产品认证 |
| **法律保护** | 发生侵权纠纷时作为权属证据 |
| **项目融资/招投标** | 知识产权是无形资产，提升估值 |

## 二、申请前准备

### 2.1 确认申请人身份

| 申请人类型 | 所需身份证明 | 费用（官方） |
|---|---|---|
| **个人** | 身份证复印件 | ~¥300 |
| **企业** | 营业执照复印件 + 公章 | ~¥1000 |

> 个人申请：著作权人 = 开发者本人
> 企业申请：著作权人 = 公司，需盖公章

### 2.2 确认软件状态

- **开发完成日期**：2026-07-16（当前版本完成）
- **是否已发表**：如未公开发布，填"未发表"
- **版本号**：建议 V1.0

### 材料 2：源代码文档（鉴别材料）

**格式要求：**
- 前 30 页 + 后 30 页，共 60 页
- 每页 50 行代码（含注释和空行）
- A4 纸，小四号字（或等宽字体 10pt）
- 页眉标注软件名称 + 版本号
- 页码连续（1-60）

**本项目具体做法：**

运行 `02-源代码文档/generate_source_doc.py` 自动生成。脚本会：
1. 从 `app/core/` 选取核心 Python 文件
2. 前 30 页取自核心模块（routes.py, builder.py 等）
3. 后 30 页取自辅助模块和 JS 管理后台代码
4. 格式化为每页 50 行
5. 输出 `源代码文档.txt`

生成后用 Word / WPS 打开，调整页边距后导出为 PDF。

详见 [03-用户手册/软件使用说明书.md](03-用户手册/软件使用说明书.md)

## 四、申请流程（时间线）

```
第 1 天     注册账号 → 填写申请表 → 上传所有材料 → 缴费
            ↓
第 1-3 天   受理通知书（材料没问题的话）
            ↓
第 30-60 天 审查（可能收到补正通知）
            ↓
第 60-90 天 获得软著证书（电子版 + 纸质版邮寄）
```

### 详细步骤

#### 第一步：注册账号

1. 访问 [中国版权保护中心](https://www.ccopyright.com.cn)
2. 点击"注册"，选择"个人用户"或"机构用户"
3. 完成实名认证（需身份证/营业执照）

#### 第二步：填写申请表

1. 登录后进入"软件著作权登记"
2. 点击"新建申请"
3. 按 [申请表填写指南](01-申请表填写参考/申请表填写指南.md) 逐项填写
4. 保存并提交

#### 第三步：上传材料

在线上传：
- 源代码文档 PDF（前 30 页 + 后 30 页）
- 用户手册 PDF
- 身份证明文件

#### 第四步：缴费

| 申请人 | 费用 |
|---|---|
| 个人 | ¥300（官费） |
| 企业 | ¥1000（官费） |

在线支付即可。

#### 第五步：等待审查

- **受理**：3 个工作日内
- **审查**：受理后 30-60 个工作日
- **补正**：如材料有问题，会收到补正通知，按要求修改后重新提交
- **发证**：审查通过后，电子证书即时可查，纸质证书约 2 周邮寄

## 五、常见问题

### Q1：源代码要交全部吗？

不需要。只交 60 页（前 30 + 后 30），每页 50 行。本项目 Python 核心代码 ~14,000 行，选 3,000 行即可。

### Q2：HTML/CSS/JS 算源代码吗？

算。软著接受多种编程语言。但建议以 Python 为主（核心逻辑），JavaScript 为辅。

### Q3：代码里有第三方库怎么办？

没关系。软著不要求 100% 原创，框架和库的 import 语句保留即可。

### Q4：软件还没上线可以申请吗？

可以。发表状态填"未发表"即可。

### Q5：申请被拒了怎么办？

通常不是"拒绝"而是"补正"——审查员指出材料问题，修改后重新提交。常见补正原因：
- 源代码页数不够 60 页
- 用户手册缺少截图
- 申请表信息与材料不一致

### Q6：软著有效期多久？

**50 年**（自然人）或 **50 年**（法人，自首次发表起算）。

## 六、本项目专属提醒

1. **代码注释是中文的** —— 这是优势。审查员能看懂代码逻辑，更容易通过。
2. **项目结构清晰** —— `app/core/` 16 个 Python 文件，职责分明，含完整认证系统（4 个新数据模型）。
3. **认证系统是亮点** —— 多因子身份管理、验证码通道、自适应密码哈希、多设备会话管理，代码逻辑完整可读。
4. **生成脚本已准备好** —— 运行 `02-源代码文档/generate_source_doc.py` 即可得到格式化的源代码文档（含 models.py 认证模型）。
5. **建议申请人** —— 如果是公司运营，用公司名义申请（便于后续高新技术企业认定）；如果目前是个人项目，先个人申请，后续可以转让。
