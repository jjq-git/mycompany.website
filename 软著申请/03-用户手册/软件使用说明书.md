# 软件使用说明书

> 软件名称：小企业静态网站生成与管理平台 V1.0
> 更新日期：2026-07-16

---

## 一、软件概述

### 1.1 产品简介

"小企业静态网站生成与管理平台"是一款面向小企业主的网站搭建与管理工具。用户无需编写任何代码，通过填写表单的方式即可完成企业展示型网站的创建、编辑和发布。

软件核心思路：将用户填写的公司信息、产品数据、页面内容生成为纯静态 HTML/CSS/JS 文件，发布后不需要服务器端程序运行，网站加载速度快、安全性高、维护成本近乎为零。

### 1.2 目标用户

- 制造业、贸易、服务业、餐饮业等小企业老板
- 不会编程，但需要专业的企业展示网站
- 网站内容更新频率较低（每 1-6 个月一次）
- 之前可能使用过 WordPress 但对维护感到困扰的用户

### 1.3 核心功能

| 功能 | 说明 |
|---|---|
| 模板选择 | 多套精美网站模板，一键切换 |
| 页面编辑 | 可视化添加/删除/排序功能模块（导航、产品展示、联系方式等） |
| 数据集管理 | 产品列表、文章列表的结构化数据增删改查 |
| 媒体管理 | 图片上传、自动压缩优化 |
| 账户中心 | 个人资料、站点管理、账号安全、回收站 |
| 静态生成 | 一键生成纯静态 HTML 网站 |
| 导出下载 | 打包整站为 ZIP 文件，可部署到任意 CDN |
| AI 翻译 | 自动翻译网站内容到多语言版本 |

## 三、安装与启动

### 3.1 获取代码

从代码仓库克隆项目到本地或服务器：

```bash
git clone <仓库地址>
cd mycompany.website11
```

### 3.2 安装依赖

```bash
pip install -r requirements.txt
```

### 3.3 配置环境变量

复制环境变量模板并根据实际情况修改：

```bash
cp .env.example .env
```

主要配置项：

| 变量 | 说明 | 是否必填 |
|---|---|---|
| SECRET_KEY | 会话加密密钥（生产环境必须修改） | 生产必填 |
| DATABASE_URL | 数据库连接地址（默认 SQLite） | 可选 |
| PLATFORM_DOMAIN | 平台部署域名 | 生产必填 |
| SMTP_HOST / SMTP_PORT / SMTP_USERNAME / SMTP_PASSWORD | 邮件发送配置 | 生产必填 |
| SMS_WEBHOOK_URL / SMS_WEBHOOK_TOKEN | 短信发送配置 | 可选 |

### 3.4 创建管理员账号

```bash
flask --app run create-user admin@example.com
flask --app run promote-admin admin@example.com
```

### 3.5 启动服务

开发环境：

```bash
python run.py
```

生产环境（使用 Gunicorn）：

```bash
gunicorn run:app -w 4 -b 0.0.0.0:8000
```

启动后访问 http://localhost:5000 进入管理后台。

## 四、功能操作说明

### 4.1 用户注册与登录

本软件支持**邮箱或手机号注册**，采用"账号 + 密码"主登录方式，同时支持验证码辅助认证。

**注册：**
1. 在登录页面点击"注册"
2. 选择注册方式（邮箱或手机号）
3. 输入邮箱地址或手机号码
4. 系统发送 6 位验证码
5. 输入验证码并设置登录密码（至少 8 位，须包含字母和数字）
6. 完成注册，自动登录

**登录：**
1. 输入已注册的邮箱或手机号
2. 输入登录密码
3. 点击"登录"进入管理后台

**找回密码：**
1. 在登录页面点击"忘记密码"
2. 输入已注册的邮箱或手机号
3. 接收并输入 6 位验证码
4. 设置新密码

**安全特性：**
- 密码使用自适应哈希算法存储，不可逆
- 验证码 10 分钟有效，最多 5 次尝试
- 支持 30 天"记住我"持久登录
- 修改密码后自动撤销其他所有设备登录

### 4.2 创建站点

1. 登录后进入仪表盘
2. 点击"创建新站点"
3. 输入站点名称（子域名，如 `mycompany`）
4. 选择网站模板
5. 点击"创建"

系统会基于模板自动生成初始网站内容（含示例页面和产品数据）。

### 4.3 编辑站点基本信息

1. 进入站点管理后台
2. 在"设置"页面配置：
   - 网站名称与标语
   - Logo 与 Favicon
   - 主色调
   - 导航菜单
   - 页眉/页脚信息
   - 联系方式

### 4.4 页面编辑

本软件采用**Block 模块化**页面构建方式。每个页面由多个功能模块（Block）组装而成：

1. 在页面列表中选择要编辑的页面
2. 点击"添加模块"
3. 选择模块类型（如：横幅、产品展示、公司介绍、联系方式等）
4. 在右侧属性面板中填写模块内容
5. 拖拽调整模块顺序
6. 点击"保存"

常用 Block 类型：

| Block 类型 | 用途 |
|---|---|
| hero_banner | 首页大图横幅 |
| feature_grid | 特色展示网格 |
| product_list | 产品列表 |
| article_list | 文章列表 |
| contact_form | 联系表单 |
| text_block | 富文本内容块 |
| image_gallery | 图片画廊 |

### 4.5 数据集管理

数据集（Dataset）用于管理结构化列表数据，如产品目录、文章列表等。

**添加产品：**
1. 进入"数据集" → "产品"
2. 点击"添加产品"
3. 填写产品名称、图片、描述、价格等信息
4. 点击"保存"

**编辑产品：**
1. 在产品列表中点击要编辑的产品
2. 修改信息后点击"保存"

**删除产品：**
1. 在产品列表中找到目标产品
2. 点击删除按钮
3. 确认删除

文章管理的操作流程同上。

### 4.6 媒体库

1. 进入"媒体库"
2. 点击"上传"选择图片文件
3. 系统自动对图片进行优化处理（压缩、多尺寸生成）
4. 在编辑内容时可以从媒体库中选择已上传的图片

支持格式：JPG、PNG、GIF、WebP

### 4.7 账户中心

账户中心是用户管理平台级个人数据的独立工作区。点击编辑器左下角用户卡片即可进入，不会丢失当前编辑状态。

**个人资料：**
- 修改昵称
- 查看登录邮箱（只读）
- 切换后台界面语言（中文简体/中文繁体/英文）
- 查看注册时间和最近登录时间

**我的站点：**
- 查看所有站点的列表（名称、模板、语言、最近发布时间）
- 点击进入编辑
- 预览站点
- 导出站点 ZIP

**账号与安全：**
- 绑定额外邮箱或手机号
- 设置主登录身份
- 解绑非主身份
- 修改登录密码
- 查看登录设备列表
- 远程撤销其他设备登录

**回收站：**
- 查看已删除的站点
- 一键恢复被删除的站点
- 被删除站点的文件和数据在恢复前完整保留

### 4.8 生成与发布

**生成静态站点：**

1. 确认所有页面内容已保存
2. 点击"生成站点"
3. 系统自动将所有内容渲染为静态 HTML 文件
4. 生成完成后可预览

**导出下载：**

1. 点击"导出站点"
2. 系统将整个静态站点打包为 ZIP 文件
3. 下载 ZIP 文件到本地

**部署到 CDN：**

将下载的 ZIP 解压后上传到任意 CDN 或 Web 服务器（如阿里云 OSS、Nginx、Netlify 等）即可上线。

### 4.9 AI 翻译

如果站点需要多语言版本：

1. 进入"翻译"页面
2. 选择目标语言
3. 点击"自动翻译"
4. 系统使用 AI 自动翻译所有页面内容
5. 用户可以手动校对和修改翻译结果

## 五、常见问题

### Q: 忘记密码怎么办？
A: 在登录页面点击"忘记密码"，输入注册的邮箱或手机号，接收验证码后即可重设密码。

### Q: 可以同时绑定邮箱和手机号吗？
A: 可以。在账户中心 → 账号与安全中，可以绑定多个邮箱和手机号，并设置其中一个为主登录身份。

### Q: 账号被盗怎么办？
A: 在账户中心 → 账号与安全中，可以查看所有登录设备并远程撤销可疑设备。建议立即修改密码，修改后其他设备会自动退出。

### Q: 网站生成后还能修改吗？
A: 可以。登录后台修改内容后重新生成即可。旧版本会被覆盖。

### Q: 误删了站点能恢复吗？
A: 能。本软件采用软删除机制，删除的站点会进入回收站，文件和数据完整保留，可以随时恢复。

### Q: 导出的 ZIP 文件包含什么？
A: 包含完整的静态网站文件（HTML、CSS、JS、图片、字体），解压后可直接部署到任意 Web 服务器。

### Q: 支持绑定自定义域名吗？
A: 支持。将生成的静态文件部署到 CDN 后，配置域名 CNAME 解析即可。

### Q: 平台关停了，我的网站还能访问吗？
A: 能。因为你的网站是纯静态 HTML 文件，只要文件在 CDN 上就永远可以访问。这也是本软件核心理念——"平台死了，用户的网站不能死"。

### Q: 网站加载速度快吗？
A: 非常快。软件内置了字体子集化（中文字体从 5-10MB 压缩至 15KB）、图片自动压缩和 WebP 转换，首屏加载时间通常在 1 秒以内。
