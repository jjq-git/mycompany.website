## git 追踪状态

| 目录/文件 | git | 说明 |
|---|---|---|
| `app/` | 追踪 | 应用代码 |
| `site_templates/` | 追踪 | 模板代码，开发者 + AI 编写 |
| `docs/` | 追踪 | 设计文档 |
| 根配置文件 | 追踪 | `.env.example`、`requirements.txt`、`run.py` 等 |
| `sites/` | 忽略 | 店主网站数据，每站一个文件夹 |
| `output/` | 忽略 | 构建产物，发布到 CDN 后即可删除 |
| `instance/` | 忽略 | SQLite 数据库文件 |
| `.env` | 忽略 | 本地环境变量（含 API Key 等敏感信息） |

## 关键设计决策

- **数据分两层**：平台级数据在数据库（`instance/app.db`），站点内容在文件系统（`sites/<id>/`）
- **模板两层结构**：页面框架用 Jinja2（`templates/`），模块片段用纯 HTML + data-* 属性（`blocks/`）
- **每种语言自包含**：`output/<site_id>/<lang>/` 是完整的独立静态站，复制即用
- **模板之间不共享 CSS**：每个模板拥有独立 `main.css`，各自维护，避免耦合
- **导出即站点**：`sites/<id>/` 复制出来 + 模板 = 完整可运行网站
