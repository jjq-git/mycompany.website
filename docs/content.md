# 店主后台（内容管理）

> 模板由开发者 + AI 用代码制作，详见 [templates.md](templates.md) 和 [architecture.md](architecture.md)。
> 本文档只讲店主用来管理网站内容的界面。

## 一、设计原则

- 不显示「块」「模板」「组件」这些技术词
- 主界面是数据列表，不是可视化编辑器
- 任何编辑都是表单，不是拖拽
- 店主**永远不接触代码、不打开任何"设计"工具**

## 二、主导航

```text
我的网站
├── 首页（点开 → 改 Banner、改宣传语、换图）
├── 产品（点开 → 看产品列表，可加 / 删 / 改）
├── 案例（点开 → 案例列表）
├── 关于我们（点开 → 富文本编辑）
├── 联系我们（点开 → 地址电话表单）
├── 设置
│   ├── 公司信息（Logo、名称、备案号）
│   ├── 主题颜色
│   ├── 自定义域名
│   ├── SEO 设置
│   ├── 第三方代码（百度统计等）
│   └── 数据导出
└── 发布（按钮）
```

## 三、添加产品的体验

```text
点击「产品」→ 看到列表 → 点「+ 添加产品」
                              ↓
                  ┌────────────────────────┐
                  │ 产品图片  [上传]         │
                  │ 产品名称  [____________] │
                  │ 简介     [____________] │
                  │ 价格     [____________] │
                  │ 详细描述  [富文本编辑器]  │
                  │ 规格参数  [+ 添加项]     │
                  │                        │
                  │ [取消]         [保存]   │
                  └────────────────────────┘
```

填完保存即可。**店主从不知道这背后涉及"数据块""模板""Jinja2"**。

## 四、上传图片的处理

- 上传时立即压缩、生成多尺寸、转 WebP
- 显示进度条（"压缩中..."）
- 显示对比："您上传 5.2MB，优化后 180KB"
- **让店主感受到平台的价值**

## 五、帮助：随手可得 + 聪明触发

老板可能 6 个月才登录一次。强制弹指引会烦，没指引又记不住。
分两层：

### 随手可得（永远在）

- 界面右上角常驻 **`?` 图标**
- 想看就点，不想看就忽略
- 不是开关，是入口

### 聪明触发（系统主动判断）

| 触发条件           | 系统行为                                                 |
| ------------------ | -------------------------------------------------------- |
| 首次进入某界面     | 自动展示一次指引（含 30 秒视频）                         |
| 距上次登录 > 60 天 | 顶部一行温和 banner：「您 4 个月没来了，看看更新？」可关 |
| 用了新功能         | 「新功能」红点提示                                       |
| 其余情况           | 不打扰                                                   |

效果：

| 用户类型     | 体验               |
| ------------ | ------------------ |
| 新用户       | 自动看到一次指引   |
| 高频老用户   | 安静，需要时点 `?` |
| 低频回归用户 | 温和提示，不强制   |

## 六、发布前检查

点「发布」时系统自动检查：

- ✅ 公司名称已填
- ✅ 联系方式已填
- ✅ 至少有 1 个产品
- ⚠️ Logo 未上传（建议上传）
- ⚠️ 首页 Banner 还在用模板默认图（建议替换）

通过则发布；有警告允许"忽略并发布"。

## 七、登录方式

**邮箱魔法链接，不要密码。**

- 输入邮箱
- 收到一封带链接的邮件
- 点击链接即登录

低频用户记不住密码。免去"忘记密码"流程。

## 八、想动一下的店主怎么办

总有店主会问："能不能改一下这个按钮颜色 / 加一段公众号二维码 / 加百度统计代码"。

我们提供四个明确的口子（详见 [publish.md](publish.md)）：

1. **自定义 HTML 块** —— 在任何页面加一段自己的代码
2. **全站 head 注入** —— 加百度统计、客服系统等脚本
3. **全站自定义 CSS** —— 微调样式
4. **整站导出 ZIP** —— 想完全控制？拿走自己改

这四个口子能消化 95% 的"我想动一下"需求，又不会污染核心产品。
