# 注册验证码：要不要买、怎么买

网站的**注册、找回密码、绑定手机/邮箱**需要给用户发验证码。分两种：

## 邮箱验证码 —— 不用买

用我们**已有的公司企业邮箱**（`@dengtec.com`，托管在阿里云）就能发，**零成本，不用买任何东西**。

- 建议在企业邮箱后台新建一个 `noreply@dengtec.com` 专门发验证码（点几下，不花钱）。
- **上线就能用。**

## 手机短信验证码 —— 要买

- **费用**：约 3~5 分钱一条（1000 条约 30~50 元），预充值用多少扣多少。
- **手续**：要用营业执照报备"短信签名"和"模板"，审核 1~2 天。
- **怎么买**：阿里云 → 开通"短信服务" → 充值 → 报备签名和模板 → 审核通过即可用。
