## 模板系统

### 模板是什么

**模板** = 一个文件夹，里面有：

- 整站的视觉风格（颜色、字体、间距）—— CSS 文件
- 各页面的结构（页眉、页脚、首页 Banner、产品页等）—— Jinja2 模板
- 每个数据块对应的字段定义（"产品"有哪些字段）—— 由 HTML 中的 data-* 属性自动推断，无需额外声明
- 一份假数据，让店主第一次进来就能看到完整效果 —— YAML seed_data

由开发者 + AI 制作，**git 管理**。店主选一个模板，整站立即可用，然后只需要把假数据替换成真数据。

**模板之间不共享 CSS。** 每个模板拥有自己独立的 `main.css`，全局样式写在模板内的 `_base.html` + `main.css` 中。不提取「全局公共 CSS」：

| 原因 | 说明 |
| --- | --- |
| 自包含 | 每个模板 = 一个完整独立的文件夹，复制即用，导出即跑 |
| 无耦合 | 制造业模板和餐饮模板视觉完全不同，共享 CSS 意味着它们产生耦合，改一处可能破坏另一处 |
| 简单 > 优化 | 省几十 KB 的 CSS 重复不值得引入共享层和判断逻辑 |
| 复用方式 | 做模板脚手架/起始模板，新模板从脚手架复制 CSS 起步，最终各自拥有独立副本 |

### 模板的文件结构

```text
site_templates/<template-name>/
├── meta.yaml                  # 模板元信息（名称、行业、封面图、版本）
├── templates/                 # 页面 Jinja2 模板
│   ├── _base.html
│   ├── index.html
│   ├── products.html          # 产品列表（数据块）
│   ├── product_detail.html    # 产品详情（数据块）
│   ├── about.html
│   ├── contact.html
│   └── blog.html
├── blocks/                    # 模块库（店主可选的通用模块）
│   ├── hero_banner/
│   │   ├── meta.yaml          # 模块元信息 + 变体定义（字段从 HTML 的 data-* 推断）
│   │   ├── template.html      # 默认变体的纯 HTML 片段
│   │   ├── variants/          # 排版样式变体模板
│   │   └── preview.png        # 后台展示缩略图
│   ├── image_text/
│   ├── product_grid/
│   └── testimonials/
├── static/                    # 静态资源
│   ├── css/
│   │   └── main.css           # 本模板的自定义 CSS（不共享）
│   └── images/
└── seed_data/                 # 假数据
    ├── settings.yaml
    ├── pages/                 # 页面种子数据
    ├── data/                  # 数据集种子数据
    │   ├── products.yaml
    │   └── posts.yaml
    └── translations.yaml      # 多语言预翻译
```

### 模板编写规范：纯 HTML + data-* 属性

`blocks/` 下的模块模板（`template.html` 及其变体）**使用纯 HTML + data-* 属性编写，不使用 Jinja2**。HTML 标签同时承担 Schema 和 Render 两个角色——标签里的文字、src、style 值即为默认值，编辑器读取展示，用户修改后写回对应元素。

详细的 data-* 属性规范（`data-type`、`data-name`、`data-href`、`data-style`、`data-hideable`、`data-source`、`data-page-size`、`data-cols`）见 **[data-attributes-reference.md](../data-attributes-reference.md)**。完整的 Block 示例（Header、Hero、Features、News 等所有类型的纯 HTML 写法）见 **[Block 示例库.md](../Block%20示例库.md)**。

核心原则：
- **HTML 本身就是数据存储**，不需要额外的 JSON 或 `<meta>` 声明
- **只开放模板作者声明过的 CSS 变量**给店主调整（通过 `data-style` + 全局注册表）
- **空值自动隐藏**——文本/媒体类字段值为空时元素自动加 `hidden`

### 块的三种类型

| 类型 | 说明 | 例子 |
| --- | --- | --- |
| 共享块 | 整站共用，改一处全站生效 | 页眉（Logo + 菜单）、页脚、面包屑 |
| 内容块 | 每页自己的内容，店主填字段 | 首页 Banner、关于我们、联系我们 |
| 数据块 | 由数据集循环生成，店主只录数据 | 产品列表 / 详情、案例集、博客 |


### 模板的参数化能力

模板 = **渲染规则 + 数据槽位**。一个好模板能覆盖大量变体：

| 参数类型 | 说明 | 例子 |
| --- | --- | --- |
| 数据列表（任意数量） | 菜单项、产品、轮播图 | 4 个菜单还是 5 个，模板不变 |
| 开关式选项 | 要不要显示某元素 | 顶栏电话、客户评价区、备案号 |
| 主题变量 | 视觉调整 | 主色、字体、圆角、间距密度 |

参数存在店主的 `SiteSettings` 中，模板渲染时读取，没有就用模板的 default。
