## 发布流程

**发布 = 模板 + 店主数据 → 静态 HTML → CDN。** 一次发布生成一个不可变的版本快照，支持一键回滚。整个流程约 10-30 秒（取决于内容量），店主看到进度条，完成后获得访问 URL。

### 完整流程

店主点「发布」按钮后：

```text
1. 检查必填项（公司信息、至少 1 个产品等）
       ↓
2. 读取站点文件夹（sites/<id>/ 下的所有 yaml + 资源）
       ↓
3. 对每种启用的语言，分别渲染：
   - 静态页面（index、about、contact）
   - 数据块详情页（每个产品一个 html）
   - 数据块列表页（一个 html + 一个 data.json）
       ↓
4. 优化资源（按语言）：
   - 字体子集化（扫描该语言的所有字符）
   - 图片确认已是 WebP（上传时已处理）
   - CSS / JS 压缩
       ↓
5. 生成附属文件：
   - sitemap.xml（含所有语言所有 URL + hreflang，详见 [SEO.md](SEO.md)）
   - robots.txt
   - llms.txt（LLM 可读的网站结构化说明书）
   - 根 index.html（语言重定向——根据浏览器首选语言 302 跳转到对应版本）
       ↓
6. 上传到 CDN（增量上传，只传变化的文件）
       ↓
7. 更新店主网站的「最新版本」指针
       ↓
8. 显示访问 URL
```

### 输出目录结构（CDN 上的样子）

```text
company_a.com/
├── index.html              ← 根：自动按浏览器语言重定向
├── zh/                     ← 简体中文整站
│   ├── index.html
│   ├── about.html
│   ├── contact.html
│   ├── products/
│   │   ├── index.html      ← 列表页
│   │   ├── data.json       ← 列表用数据
│   │   └── product_1.html  ← 详情页（SEO）
│   ├── images/
│   ├── files/
│   ├── css/
│   ├── fonts/              ← 子集化后的中文字体
│   └── js/
├── zh-Hant/                 ← 繁体中文整站（同样结构，资源完全独立）
├── en/                     ← 英文整站（同样结构，资源完全独立）
├── sitemap.xml
├── robots.txt
└── llms.txt
```

**核心原则：每个语言目录是自包含的整站，没有共享资源目录。** 单语言导出 = 复制一个文件夹就能跑。

### 字体子集化（关键差异化）

中文字体动辄 5-10 MB。发布时扫描所有页面统计实际用到的字符，从字体文件中提取这些字符做成小字体（一般 10-30 KB）。

| 方式 | 字体文件大小 | 首屏字体加载 |
| --- | --- | --- |
| 直接用完整字体 | 9.4 MB | 3-8 秒 |
| 用系统字体凑合 | 0 | 立刻（但难看） |
| **我们：子集化** | **15 KB** | **< 0.1 秒** |

- 每次发布都重新生成字体（店主可能加了新字符）
- 按语言分别子集化（英文不需要中文字体）
- 只允许使用明确可商用的字体（思源、阿里普惠、OPPO Sans 等）

### 图片处理

图片**在店主上传时就处理**（不在发布时）：

| 用途 | 尺寸 | 格式 |
| --- | --- | --- |
| 缩略图（卡片用） | 600 × 450 | WebP |
| 中图（详情用） | 1200 × 900 | WebP |
| 原图（备份） | 原始尺寸 | WebP |

显示进度条（"压缩中..."），显示对比："您上传 5.2MB，优化后 180KB"——让店主感受到平台的价值。

### 上传大小限制

| 类型 | 单文件上限 |
| --- | --- |
| 图片 | 5 MB |
| PDF / 文档 | 20 MB |
| 视频 | 50 MB |

视频限制 50 MB：超过此大小的视频强制要求外链 YouTube / 腾讯视频 / B 站，既保护储存与带宽，也保护店主体验（自托管大视频加载慢）。

### 列表页 vs 详情页（混合渲染策略）

| 输出 | 形式 | 用途 |
| --- | --- | --- |
| 详情页 | 每个条目一个预生成 HTML | SEO 关键，被搜索引擎抓取 |
| 列表页 | 一个 HTML + data.json + 浏览器 JS | 处理筛选、排序、分页 |

源数据只有一份 `data/<name>.yaml`，生成器按需抽字段。

### 发布历史与回滚

每次发布生成一个版本快照。店主可以：
- 看到发布历史（时间、版本号、文件数、大小）
- 一键回滚到任意旧版本

最多保留 10 个版本，更老的自动清理。
