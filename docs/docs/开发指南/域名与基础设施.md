## 域名与 URL 规划

**平台域名架构分三层：** 平台主站（mycompany.website）、店主免费子域（slug.mycompany.website）、店主自定义域名。所有站点通过阿里云 OSS + CDN 对外服务，SSL 由 Let's Encrypt 自动签发和续期。

### 自定义域名

店主可以绑定自己的域名（如 `www.baidu.com`）。配置流程和 SSL 管理见下方 **[基础设施：CDN + SSL](#基础设施cdn--ssl)**。

### 子域分配

```text
mycompany.website                    平台介绍站（落地页）

<slug>.mycompany.website             店主免费子域名（自动分配）

docs.mycompany.website               平台文档站

design.mycompany.website             店主后台
```

保留子域（不能被店主注册成 slug）：`docs`、`design`、`www`、`api`、`admin`、`app`、`cdn`、`assets`、`mail`、`blog`、`status`、`help`、`about`。

### 多语言 URL 路径

```text
com-a.mycompany.website/zh/         简体中文（默认）
com-a.mycompany.website/zh-Hant/    繁体中文
com-a.mycompany.website/en/         英文
com-a.mycompany.website/            语言选择首页（hreflang + 跳转）
```

- 不在根路径直接渲染任何语言版本，所有内容都在 `/zh/`、`/zh-Hant/`、`/en/` 子路径里
- 根路径生成语言选择首页，含 `hreflang` 标签 + JS 跳转 + `<meta refresh>` 兜底

### 预览 URL

```text
com-a.mycompany.website/_preview/<token>/       预览未发布的版本
com-a.mycompany.website/_preview/<token>/en/    预览的英文版
```

预览放在主子域下（不在 design 域），保证字体加载、相对路径行为跟生产一致。

## 基础设施：CDN + SSL

### 决策

MVP 阶段：**阿里云 OSS + CDN + 云解析（性能）+ Let's Encrypt（SSL）**。

- 国内用户访问最快（移动 50ms vs Cloudflare 800ms）
- SSL 用 Let's Encrypt（无配额限制），通过 ACME 自动签发和续期
- 不用阿里云免费证书（配额 20 张/年，早晚要换）

### 桶模式：共享桶 + 路径分割

MVP 推荐共享桶 + 路径前缀（`bucket_path_prefix = "youngku/"`），后期高级版可选独立桶。

### 自定义域名流程

```text
1. 店主输入域名 → 后台调 AddCdnDomain → 返回 CNAME 目标
2. 店主去自己的 DNS 配 CNAME 指向
3. 系统轮询检测 DNS 生效
4. 启动 ACME 流程申请 Let's Encrypt 证书（DNS-01 验证）
5. 证书 + 私钥上传到阿里云 CDN
6. 启用 CDN 加速 → 通知店主上线
```

每步都是 `provisioning_jobs` 记录，状态机驱动，失败可重试。

### SSL 自动续期

90 天周期，提前 30 天开始续。后台 cron job 每天扫描即将过期的证书，自动重走 ACME 流程。
