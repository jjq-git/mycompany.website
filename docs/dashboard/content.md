# 用户后台（内容管理）

> 主题由开发者用代码做（见 [themes/README.md](../themes/README.md)）；本文只讲用户管理内容的界面。

## 一、原则

- 不出现「块 / 模板 / 组件 / Jinja2」等技术词
- 主界面是数据列表，编辑都是表单（非拖拽、非可视化编辑器）
- 用户不接触代码

## 二、主导航

```text
我的网站
├── 首页（改 Banner / 宣传语 / 图）
├── 产品（列表，可加 / 删 / 改）
├── 案例（列表）
├── 关于我们（富文本）
├── 联系我们（地址电话表单）
├── 设置
│   ├── 公司信息（Logo / 名称 / 备案号）
│   ├── 主题颜色
│   ├── 语言与翻译（源语言、加目标语言、逐条 AI 翻译）
│   ├── 自定义域名
│   ├── SEO 设置
│   ├── 第三方代码（百度统计等）
│   └── 数据导出
└── 发布
```

## 三、编辑（以加产品为例）

「产品」→ 列表 →「+ 添加产品」→ 填表单：产品图片、名称、简介、价格、详细描述（富文本）、规格参数（可加多项）→ 保存。

## 四、图片上传

上传即压缩、生成多尺寸、转 WebP；显示进度与体积对比（如 5.2MB → 180KB）。

## 五、帮助

- 右上角常驻 `?` 入口
- 首次进某界面：自动展示一次指引
- 距上次登录 > 60 天：顶部温和 banner（可关）
- 新功能：红点提示

## 六、发布前检查

点「发布」自动检查：

- 必填：公司名、联系方式、≥ 1 个产品
- 建议：Logo、替换首页默认 Banner、补未翻译的语言

有警告可「忽略并发布」。

## 七、登录

邮箱魔法链接，无密码：输入邮箱 → 收邮件 → 点链接登录。

## 八、多语言

源语言填内容 → 在「设置 → 语言与翻译」逐条 AI 翻译到目标语言（译文存 `lang/<目标语言>/`，不覆盖源语言）。详见 [i18n.md](../site/i18n.md)。

## 九、想动一下的用户

四个口子（详见 [publish.md](../site/publish.md)）：自定义 HTML 块、`<head>` 注入、全站自定义 CSS、整站导出 ZIP。
