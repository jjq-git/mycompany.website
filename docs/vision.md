# 产品定位

## 一句话

> **小企业的"不会坏的网站"。发布出去就像发了一份 PDF —— 5 年后还在那里。**

## 核心洞察

> **小企业网站根本不需要"程序"，只需要"文件"。**

更新频率每 1-6 个月一次的网站，没有理由跑一个 24×7 的服务器。
做成静态文件发出去，结束。

## 给谁

| 适合                       | 不适合                             |
| -------------------------- | ---------------------------------- |
| 制造业、贸易、服务业小公司 | 大型企业                           |
| 老板自己上手               | 需要复杂用户系统                   |
| 展示型网站                 | 在线交易 / 电商                    |
| 内容更新 1-6 个月一次      | 每天发新文章的媒体                 |
| 不会编程                   | 程序员（去用 Hugo / Astro 更顺手） |

## 七个核心信念

### 1. 小企业网站不需要"程序"，只需要"文件"

输出永远是静态 HTML。
程序需要维护、要升级、有漏洞；文件不需要。
平台关停了，文件还在。

### 2. 用户应该填表，不该写代码

写 HTML / CSS / JS 是程序员的事。
老板的工作是填「公司名」「产品价格」「联系电话」。

### 3. 模板要少而精

Shopify 官方只有 12 套模板，撑起了千亿生意。
**3 套精美模板 > 30 套粗糙模板**。
每套模板必须找设计师做一次（一次性投入，长期受益）。

### 4. 平台死了，用户的网站不能死

用户敢交钱给我们，是因为相信「半年后我能登回来」。

万一我们关停：

- 已发布的网站继续工作（CDN 上的静态文件不会消失）
- 用户能一键导出整站 ZIP，丢到任何 CDN 都能跑

**这是信任锚点，不是安慰奖。**

### 5. 速度也是一种"不会坏"

中文网站慢的常见原因：

- 中文字体动辄 5-10 MB
- 图片不压缩，老板上传 5MB 手机原图
- 各种第三方追踪脚本拖慢首屏

我们要做：

- 字体子集化（只打包实际用到的字符）
- 图片自动压缩 + 多尺寸 + WebP
- 不强加任何第三方脚本

目标：首屏 < 1 秒，PageSpeed > 95 分。

### 6. 简单 > 优化

在小企业站规模下（< 100MB，不含视频），别为节省几十 MB 储存或一些缓存命中率
而引入架构复杂度。

例：多语言网站的图片、PDF、CSS、视频都按语言完全复制 —— 不去判断"是否共享"。
省几十 MB 不值得维护"哪些文件共享、哪些不共享"的判断逻辑。

大视频（> 50MB）建议外链到 YouTube / 腾讯视频 / B 站，
平台不为这种特殊情况增加架构复杂度。

### 7. 低频用户友好

老板可能 6 个月才登录一次。这意味着：

- **不要密码登录**，用邮箱魔法链接
- **帮助随手可得**：右上角常驻 `?` 图标；新用户首次自动展示一次；超过 60 天未登录会有温和的回归提示
- **主动邮件提醒**：「您 4 个月没更新了」

## 不做的事（同样重要）

| ❌ 不做                              | 为什么                                   |
| ------------------------------------ | ---------------------------------------- |
| 引入可视化模板编辑器（Grapes.js 等） | 模板由开发者 + AI 写代码做，git 管理     |
| 用户改 CSS / HTML / JS               | 模板升级会冲突                           |
| 30 套模板                            | 资源稀释                                 |
| 在 Phase 1 MVP 里做多语言            | 留到 Phase 2                             |
| 密码登录                             | 6 个月后用户找不回密码                   |
| 整页所见即所得编辑器                 | 复杂度爆炸，需求其实是"换模板"           |
| 评论 / 论坛 / 用户系统               | 不是展示型网站的必需                     |
| 在线交易                             | 用 Shopify / 有赞，不是我们的赛道        |

## 成功的样子

- 用户首次注册到发布上线 < 30 分钟
- 首屏加载 < 1 秒
- 80% 的用户不需要客服
- 用户主动推荐："终于不用维护了"

## 这个项目的视角

「自己也会用」是这个产品的工程视角 —— 决策犹豫时问一句：
**"如果我自己用这个产品，这样做合理吗？"**
