## 名词

| 名词          | 含义                                                                             |
| ------------- | -------------------------------------------------------------------------------- |
| 主题（Theme） | 一套预设的整站设计（皮肤），含布局、block、样式、初始内容；存于 `themes/<name>/` |
| 块（Block）   | 网站页面的组成单元（页眉、产品列表、联系表单等）                                 |
| 共享块        | 整站共用的块（页眉、页脚），改一处全站生效                                       |
| 内容块        | 用户填字段的块（首页 Banner、关于我们）                                          |
| 数据块        | 由数据集循环生成的块（产品列表、案例集）                                         |
| 数据集        | 一类内容的集合（"产品"是一个数据集，"案例"是另一个）                             |
| 数据条目      | 数据集的一条记录（一个产品、一篇案例）                                           |
| 子集化        | 把字体文件中用不到的字符删掉，只保留实际用到的                                   |
| 用户          | 使用平台建网站的人                                                               |
| 主题开发者    | 平台方（你 + 外包），制作主题的人                                                |
| 访客          | 浏览用户网站的人（如访问用户的站 rimu.me），看不到我们平台的存在                 |
