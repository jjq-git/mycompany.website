## 名词

| 名词                | 含义                                                                             |
| ------------------- | -------------------------------------------------------------------------------- |
| 主题（Theme）       | 一套预设的整站设计（皮肤），含布局、block、样式、初始内容；存于 `site_templates/<name>/` |
| 布局（Layout）      | 主题内 Jinja2 页面骨架（`_base.html`、`index.html` 等）                          |
| 块（Block）         | 网站页面的组成单元（页眉、产品列表、联系表单等）                                 |
| 共享块              | 整站共用的块（页眉、页脚），改一处全站生效                                       |
| 内容块              | 用户填字段的块（首页 Banner、关于我们）                                          |
| 数据块              | 由数据集循环生成的块（产品列表、案例集）                                         |
| 数据集              | 一类内容的集合（"产品"是一个数据集，"案例"是另一个）                             |
| 数据条目            | 数据集的一条记录（一个产品、一篇案例）                                           |
| 面板（Panel）       | 后台右侧属性编辑面板，选中 block 后显示可编辑字段                                |
| 变体（Variant）     | 同一功能区的不同样式选择（header style-a / style-b）                             |
| 片段（Fragment）    | 面板渲染方式：复用同一模板，去掉外壳只渲染内容区                                 |
| 字段（Field）       | 用户在后台填写的单个输入项（文本、图片、颜色等）                                 |
| 源语言              | 用户建站时选的第一种语言，所有内容以此语言为基准                                 |
| 魔法链接            | 无密码登录：输入邮箱 → 收到含 token 链接 → 点击登录                              |
| 构建（Build）       | 源内容（YAML）+ 主题渲染成 `output/` 静态站                                      |
| 子集化              | 字体文件删掉用不到的字符，只保留实际用到的                                       |
| 用户                | 使用平台建网站的人                                                               |
| 主题开发者          | 平台方（你 + 外包），制作主题的人                                                |
| 访客                | 浏览用户网站的人，看不到我们平台的存在                                           |

> **术语说明**：文档统一用「主题（Theme）」指代生成用户网站的那套皮肤，`template` 一词只留给后台 Flask 模板（`app/templates/`）。代码中目前仍沿用旧名 `Template` / `site_templates/`，术语重命名见 [TODO-code.md](TODO-code.md)。
